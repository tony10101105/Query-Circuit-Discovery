## Setup
Install torch:
```
pip install torch==2.8.0 torchvision==0.23.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
```
Install required packages:
```
pip install requirements.txt
```

## Dataset Download
We provide intermediate data (e.g., score matrix) on the [HF data repo](https://huggingface.co/datasets/tony10101105/Query-Circuit-Dataset) for fast replication.
